# Meu Portfólio Pessoal

**Aluno:** Luis Fernando Ferreira dos Santos

## Descrição do projeto
Este projeto é um portfólio pessoal desenvolvido para apresentar meu perfil, meus projetos e minhas informações de contato. O objetivo é mostrar meus conhecimentos e minha evolução no curso Técnico em Desenvolvimento de Sistemas.

## Tecnologias utilizadas
- HTML5
- CSS3
- Bootstrap
- GitHub Pages

## Funcionamento do projeto
O site possui um menu de navegação que permite acessar as seções Perfil, Projetos e Contato. A página apresenta meus dados pessoais, projetos desenvolvidos e formas de contato.

## Recurso novo adicionado
Foi adicionada uma animação aos cartões da seção Meus Projetos. Quando o usuário passa o mouse sobre um cartão, ele aumenta levemente de tamanho e sobe um pouco.

## Como o recurso foi implementado
A animação foi implementada utilizando CSS, com o recurso `:hover` e a propriedade `transition`. Também foi utilizada a propriedade `transform` para movimentar e aumentar os cartões suavemente quando o mouse passa sobre eles.
